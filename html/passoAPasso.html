Tutorial Interativo: Formulário + FormSubmit

Aprenda passo a passo como criar um formulário HTML, configurar o FormSubmit e enviar informações para um e-mail.

Etapa 1 de 8 12%
ETAPA 1

Entenda o fluxo

O HTML cria o formulário. O navegador envia os dados. O FormSubmit recebe as informações e encaminha para o e-mail configurado.

Usuário preenche o formulário
→
Navegador envia com POST
→
FormSubmit recebe os dados
→
E-mail recebe a mensagem
<form>Agrupa os campos.
actionDefine o destino.
POSTEnvia os dados.
nameNome da informação enviada.
ETAPA 2

Crie o arquivo HTML

Neste tutorial tudo está em um único arquivo. Crie um arquivo chamado index.html.

📁 formulario-aula
📄 index.html

Estrutura básica

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Formulário</title>
</head>

<body>

    <h1>Fale Conosco</h1>

</body>
</html>
Faça agora: crie o arquivo index.html e cole a estrutura acima.
ETAPA 3

Crie o formulário

<form>

    <label for="nome">Nome</label>
    <input type="text" id="nome" name="nome">

    <br><br>

    <label for="email">E-mail</label>
    <input type="email" id="email" name="email">

    <br><br>

    <label for="assunto">Assunto</label>
    <input type="text" id="assunto" name="assunto">

    <br><br>

    <label for="mensagem">Mensagem</label>
    <textarea id="mensagem" name="mensagem" maxlength="90"></textarea>

    <br><br>

    <button type="submit">Enviar Mensagem</button>

</form>
<label>Identifica o campo.
type="text"Campo de texto.
type="email"Campo de e-mail.
idIdentificação do elemento.
nameNome da informação enviada.
textareaMensagem maior.
submitEnvia o formulário.
Use maxlength="90" e não maxlength="90px".
ETAPA 4

Configure o FormSubmit

Agora o formulário precisa saber para onde enviar os dados. 

<form action="https://formsubmit.co/vslssbarbosa@gmail.com" method="POST">
action Indica para onde os dados serão enviados.
method="POST" Indica a forma usada para enviar os dados.
Leia assim:
“Envie os dados deste formulário para o FormSubmit usando POST.”
ETAPA 5

Adicione os campos hidden

Esses campos são enviados ao FormSubmit, mas não aparecem para o usuário. 

<input type="hidden" name="_subject" value="Nova mensagem do site">

<input type="hidden" name="_template" value="table">

<input type="hidden" name="_next"
       value="http://127.0.0.1:5500/sucesso.html">
_subjectDefine o assunto do e-mail.
_templateDefine a organização do e-mail.
_nextDefine a próxima página após o envio.
hiddenCampo oculto para o usuário.

Dados do usuário

nome email assunto mensagem

Configurações do FormSubmit

_subject _template _next
ETAPA 6

Crie uma página de sucesso

Como estamos usando um único arquivo, o exemplo abaixo mostra como seria uma página separada chamada sucesso.html. 

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Mensagem enviada</title>
</head>

<body>

    <h1>Mensagem enviada com sucesso!</h1>

    <p>Obrigado por entrar em contato.</p>

    <a href="index.html">Voltar</a>

</body>
</html>
Em ambiente local, o _next pode ser: http://127.0.0.1:5500/sucesso.html. Quando publicar o site, troque pelo endereço real.
ETAPA 7

Teste e ative o FormSubmit

  1. 1 Abra o index.html usando Live Server.
  2. 2 Preencha o formulário.
  3. 3 Clique em Enviar Mensagem.
  4. 4 Na primeira vez, confirme a ativação no e-mail de destino.
  5. 5 Envie o formulário novamente.
  6. 6 Verifique se a mensagem chegou.
Preencher
→
POST
→
FormSubmit
→
E-mail
Se o Live Server estiver usando outra porta, troque o endereço do _next.
